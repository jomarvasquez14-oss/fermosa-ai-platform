# M0055 — Operational Analytics

> Status: **Complete** (2026-07-14) · Branch: `feature/crm-browser-connector`
> Operational analytics over **stored evidence snapshots only** — the
> `NormalizedCrmPatientRecord`s the platform already sealed (ADR-035). The live
> CRM is never queried. Pure builder + a bounded snapshot reader + a role-gated
> page reusing the M0053 charts.

## Structure

- `services/analytics/analytics-builder.ts` — **pure** `buildAnalytics(records)`:
  deterministic aggregation, no Prisma/Date.now/I/O.
- `services/analytics/analytics-service.ts` — `getAnalytics()`: reads the most
  recent snapshot records (`AuditEvidenceSnapshot.record`, bounded to 5000),
  **schema-validates each** (a corrupt record is skipped loudly, not trusted),
  and calls the builder. Never touches the live CRM.
- `features/analytics/components/analytics-view.tsx` — reuses the dependency-free
  `BarChart` / `TrendChart` (M0053).
- `app/(app)/analytics/page.tsx` — gated by `reports:view` (Auditor / Super-Admin),
  plus `/analytics` in `ROUTE_ACCESS` (middleware) and the sidebar nav.

## Metrics

- **Top branches** — treatment volume by branch.
- **Treatment frequency** — by procedure (top 10).
- **Revenue trends** — invoice `amountPaid` summed by month + a total.
- **Package completion** — per (patient, package): sessions seen vs the package
  total → completed / in-progress counts + average percent.
- **Staff activity** — treatments by performing staff name (top 10).
- **Staff by role** — by `performedBy.role`.
- **Edit activity by target** — activity events bucketed (treatment / invoice /
  payment / user / package / other) from log name + description.
- **Branch comparison** — treatments and distinct patients per branch.

## Honest limits (documented, not papered over)

- **Staff roles:** the normalized contract (ADR-027) carries only
  aesthetician / encoder / **unknown**. The spec's "salesperson / IV therapist"
  granularity is not in the record — those are bucketed as `unknown`, surfaced
  with a note in the UI, never guessed.
- **Branch revenue:** invoices carry no branch in the record, so revenue is
  clinic-wide (branch comparison uses treatments + patients, not revenue).
- **Empty state:** with zero snapshots (as in a fresh install), every number is
  zero/null and the page shows an explicit "No analytics yet" — no fabrication.
